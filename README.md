# Duel Arena 3D

2人対戦のブラウザ向け3Dシューティングゲームです。GitHub Pagesで静的配信します。

## 起動経路

`index.html` → `src/main.js` → `src/game.js`

`src/main.js` は安定した小さなエントリポイントです。ゲーム本体の処理は現在 `src/game.js` にあり、機能単位で段階的に分割しています。

Three.jsは`index.html`のimport map経由でjsDelivrから読み込みます。ゲーム用モデル・音声は`assets/`配下に配置しています。

## 現在の構成

- `index.html` — 画面UIとゲームエントリ
- `src/main.js` — 安定した起動用エントリポイント
- `src/game.js` — 現在のゲーム本体。段階的に責務を分離中
- `src/arena-config.js` — アリーナ共通定数（`ARENA` / `SPAWN_X`）
- `src/ui.js` — バナー表示と試合結果表示
- `src/loadout-config.js` — キャラクター・装備・ビルドの静的設定
- `style.css` — UI・画面レイアウト
- `assets/models/characters/` — 使用中の6キャラクター
- `assets/models/weapons/` — 使用中の6武器と依存ファイル
- `assets/models/stage/` — 使用中のステージ部品と依存ファイル
- `assets/audio/` — BGM・カウント音声
- `.github/workflows/deploy-pages.yml` — GitHub Pagesデプロイ

## リファクタリング方針

機能追加より先に、現在の大きな `src/game.js` を安全に分解します。

- 新しい実装を追加したまま古い実装を残さない
- 新ファイルへ移した定義は、元ファイルから同じ変更で削除する
- 同じ責務・同じ名前の実装を複数作らない
- ファイル名、import名、export名、変数名の大文字小文字まで一致を確認する
- 分割だけの変更では、挙動変更や新機能追加を混ぜない
- 一度に大きく書き換えず、責務ごとに小さく移動する
- 構文・重複・参照関係を確認してから `main` に反映する

### 分割予定

1. アリーナ設定 — `arena-config.js` へ段階的に集約
2. キャラクター・装備・ビルド設定 — `loadout-config.js`
3. UI表示処理 — `ui.js`
4. 入力処理 — `input.js`
5. カメラ・レンダリング — camera系モジュール
6. ステージ生成 — arena系モジュール
7. プレイヤー・戦闘処理 — combat/player系モジュール

※ 未完成の分割ファイルを旧実装と並存させることはしません。安全に旧定義を削除できる状態になってから同一変更で反映します。

## 分解完了後の実装予定

分解と安定化が終わった後、既存の対面2人対戦を土台にゲーム完成度を上げます。

### 1. 8ステージの本格3D化

現在の8アリーナを、使用中の3Dステージ素材を活かして本格的なアリーナへ仕上げます。

- Square
- Four Pillars
- Ring
- Cross
- Hex
- Twin Fort
- Bush Field
- Crate Yard

見た目だけを増やすのではなく、ステージごとの遮蔽物・動線・戦いやすさまで調整します。

### 2. 見た目と当たり判定の一致

壁・柱・木箱などの3Dモデルとコライダーを揃え、見た目では通れそうなのに当たる、または見た目では壁なのに通れる、といったズレを減らします。

### 3. 対面2人プレイの操作改善

- P2側の向きと操作感の最適化
- タッチ操作の分かりやすさ改善
- スマホ・タブレットでの対面プレイ調整
- キーボード・コントローラー操作との整合

### 4. カメラ・画面構成の調整

- トップビューの見やすさ改善
- 2分割アリーナカメラの調整
- キャラクターサイズと画面内情報量の最適化
- ステージ全体と対戦相手を把握しやすい画角への調整

### 5. 戦闘バランス調整

既存の射撃、HP、KO、SUPER、防御、Power Core、破壊可能オブジェクトを土台に、以下を詰めます。

- 射程
- 弾速
- ダメージ
- キャラクターサイズ
- 当たり判定
- ノックバック
- 防御性能
- SUPER性能
- ステージごとの有利不利

新しい要素を大量追加する前に、既存システムだけで対戦が十分に面白くなることを優先します。

## デプロイ

`main`へのpushでGitHub Pagesへデプロイします。

デプロイ前に少なくとも以下を確認します。

- `src/main.js` の構文
- `src/game.js` の構文
- `src/arena-config.js` の構文
- `src/ui.js` の構文
- `src/loadout-config.js` の構文
- `index.html` が正しいエントリポイントを参照していること
- 現在のカメラ／レンダリング経路に必要な主要関数が存在すること
