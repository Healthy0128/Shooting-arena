# Shooting Arena / Duel Arena 3D

1台のスマホ・タブレット・PCを2人で共有して遊ぶ、見下ろし2.5Dのローカル1対1シューティング。

## 現在の実装

- 6キャラクター
- 8アリーナ
- 2人同時ツインスティック
- 射撃 / HP / KO / 3KO先取
- キャラ別SUPER
- 壊れる箱
- 草むらステージ
- KayKit CC0 3Dキャラクター
- CC0 BGM自動取得
- サドンデスBGM切替
- PWA / iPhoneホーム画面追加対応
- Service Worker
- GitHub Pages自動デプロイ

## iPhone

SafariでPagesのURLを開き、共有 → ホーム画面に追加 → Webアプリとして開く → 追加。

## BGM

GitHub Actionsのビルド時にOpenGameArtのCC0曲を取得します。

- Empacotatron / Fupi — CC0
- Trance Boss Battle / MintoDog — CC0
- Space Boss Battle / MintoDog — CC0

## 3D素材

KayKit Character Pack: Adventurers 1.0 / Skeletons 1.0 をランタイム読み込み。いずれもCC0 1.0。
